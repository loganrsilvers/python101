# Python Art of Code

This repository is a collection of Python-based sound experiments created for my Art of Code class. The project explores sound generation, audio processing, and algorithmic composition through a series of small scripts and demos.

## Overview

Each file in this repository explores a different idea in creative coding and audio programming. Together, they form a set of experiments centered on synthesis, frequency analysis, MIDI, and signal processing.

The final project for the class is `ca4.py`, which implements an additive sawtooth synthesizer.

## Requirements

This project uses:

- Python 3
- numpy
- soundfile
- sounddevice

## Files

- `audioeffects/` - Additional audio effect utilities.
- `audioshuffle.py` - Audio rearrangement / transformation experiment.
- `ca2.py` - Earlier course project or synthesis experiment.
- `ca4.py` - Final project: additive sawtooth synth.
- `frequencies.py` - Frequency-related experiment.
- `midi.py` - MIDI-related experiment.
- `primeNumbers.py` - Algorithmic experiment based on prime numbers.
- `synth.py` - Sound synthesis experiment.
- `zerocrossing.py` - Zero-crossing / signal analysis experiment.
- `stereo.wav` - Example audio file.
- Demo audio files - Included for testing and listening to the output of the scripts.

## Running the code

Install the required packages, then run any script directly with Python:

```bash
python ca4.py
```

You can also try the demo audio files included in the folder as examples of the project outputs.

## Project goal

The goal of this repository is to explore how code can be used creatively to generate and transform sound. Rather than one single application, the repo documents a series of experiments that build toward the final additive synth project.

## Final project

`ca4.py` is the strongest and most complete piece in the repository. It demonstrates additive synthesis by building a sawtooth waveform from multiple harmonics and reflects the creative and technical ideas developed throughout the earlier experiments.
